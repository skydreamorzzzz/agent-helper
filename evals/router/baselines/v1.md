# Router Benchmark v1 Baseline

Dataset: `router-v1`

Split policy:

- `dev`: 42 examples for threshold, prototype, and cascade iteration.
- `test`: 18 examples for stage-level validation.
- Each split covers all six routes: `direct_answer`, `single_tool`, `web_lookup`, `planned_task`, `deep_research`, `clarification`.

Run context:

- Parent commit at run time: `7bf03f8`
- Runner command examples:
  - `python -m evals.router.runner --mode constraint_only --split test`
  - `python -m evals.router.runner --mode lexical_baseline --split test`
  - `python -m evals.router.runner --mode current_hybrid --split test`

## Mode Definitions

- `constraint_only`: `ConstraintRouter + direct_answer fallback`; no Jaccard `SemanticRouter`, no LLM.
- `lexical_baseline`: current `RequestRouter` without LLM; `ConstraintRouter + Jaccard SemanticRouter + fallback`.
- `current_hybrid`: current `RequestRouter` with LLM fallback/escalation.

## Representative Failures

### constraint_only / lexical_baseline

- `route_028`: `当前 NVIDIA 股价是多少？`
  - expected `web_lookup`, predicted `direct_answer`
  - Failure mode: current-price lexical coverage is incomplete.
- `route_040`: `Read draft.md, polish it, and save the revised version to final.md`
  - expected `planned_task`, predicted `single_tool`
  - Failure mode: English multi-step file transformation is caught by hard single-tool file logic before semantic/LLM can help.
- `route_049`: `Compare the latest OpenAI, Anthropic, and Google model pricing and cite sources`
  - expected `deep_research`, predicted `web_lookup`
  - Failure mode: current-information signal dominates multi-source comparison unless LLM is allowed to judge.
- `route_058` / `route_059` / `route_060`
  - expected `clarification`, predicted `direct_answer`
  - Failure mode: vague or missing-argument requests outside the current Chinese hard-coded patterns fall through to direct answer.

### current_hybrid

- `route_009`: `What happened in 2023-01-01?`
  - expected `direct_answer`, predicted `web_lookup`
  - Failure mode: LLM treats specific historical-date questions as external lookup.
- `route_010`: `帮我解释一下这段需求的含义，不要执行任何工具`
  - expected `direct_answer`, predicted `clarification`
  - Failure mode: LLM prioritizes missing referenced content over the route label chosen for direct explanation.
- `route_040`: `Read draft.md, polish it, and save the revised version to final.md`
  - expected `planned_task`, predicted `single_tool`
  - Failure mode: hard constraint returns `single_tool` before LLM escalation, so hybrid cannot recover.

## Notes

The identical `constraint_only` and `lexical_baseline` test results show that the current Jaccard semantic layer does not improve this split. The `current_hybrid` result improves clarification, current fact, and research comparison boundaries, but hard constraint ordering still blocks correction for some English multi-step file tasks.
