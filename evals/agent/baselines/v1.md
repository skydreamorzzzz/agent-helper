## Notes

This baseline intentionally does not fix failures discovered by E2E evaluation. It establishes task success rate and failure-stage attribution as the next optimization target.

The strongest next signal is not Router micro-tuning. The current failure distribution points to:

1. clearer handling of write-only requests that include natural-language content after the file path;
2. planner artifact validation around transform/write chains;
3. explicit recovery behavior for failed required web lookups;
4. clearer expected semantics for permission-rejected tasks.
